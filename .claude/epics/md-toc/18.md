# Task: Nested TOC rendering

## Description

Join the parser and the slug generator into the artifact users actually see: a nested Markdown list where each entry links to its heading's anchor.

Indentation is relative, not absolute. A document whose shallowest heading is `##` must render that heading at column zero rather than pre-indented — otherwise every README that reserves `#` for the title would produce a TOC indented one level too deep. The renderer therefore computes the minimum level present across the supplied headings and indents two spaces per level below that baseline, satisfying the PRD's "two spaces of indentation per heading level" while keeping the output flush left.

This module owns the single `seen` dict for the document, threading it through every `slugify` call so duplicate headings disambiguate in document order.

## Acceptance Criteria

- [ ] `render_toc` returns a Markdown bullet list, one line per heading, in document order.
- [ ] Each entry has the form `- [Title](#slug)`, linking to the heading's anchor.
- [ ] The shallowest heading level present renders at zero indentation.
- [ ] Each level below the shallowest adds exactly two spaces of indentation.
- [ ] A document whose headings start at `##` renders identically to one starting at `#`, modulo the titles.
- [ ] A skipped level (`#` followed directly by `###`) indents by the level difference without crashing or collapsing.
- [ ] Duplicate heading titles receive `-1` / `-2` suffixed anchors, because one `seen` dict is shared across the whole render.
- [ ] The link text preserves the heading's original casing and inline punctuation, even though the anchor is slugified.
- [ ] An empty heading list renders as an empty string rather than raising.
- [ ] Output is newline-joined with no trailing blank line, so task 13's splice can insert it between markers without accumulating whitespace on repeat runs.
- [ ] `tests/test_render.py` covers each criterion above as a distinct `unittest` test method, including a fixture exercising nesting, duplicates, and a non-`#` starting level together.

## Technical Details

Paths owned by this task, and no others:

- `md_toc/render.py`
- `tests/test_render.py`

Signature implemented:

```python
def render_toc(headings: list[Heading]) -> str:
```

Imports `Heading` from `md_toc.types` (task 12) and `slugify` from `md_toc.slug` (task 16). Return `""` immediately on an empty list. Otherwise compute `base = min(h.level for h in headings)`, create a single `seen: dict[str, int] = {}`, and for each heading emit `"  " * (h.level - base) + f"- [{h.title}](#{slugify(h.title, seen)})"`. Join with `"\n"` and do not append a trailing newline — the splice routine in task 13 controls surrounding blank lines, and duplicating that responsibility here is what would break `--in-place` idempotency.

The `seen` dict must be created once per call and passed to every `slugify` invocation; creating it per heading would silently disable duplicate disambiguation and is worth an explicit regression test.
