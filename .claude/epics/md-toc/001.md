# Task: Package scaffold, Heading type, and exit-code constants

## Description

Create the `md_toc/` package and the shared vocabulary every other task compiles against: the `Heading` value type that the parser produces and the renderer consumes, and the three exit-code constants that define the CLI's contract with CI.

Nothing in this task performs I/O or parsing. Its only job is to exist first, so that tasks 002 and 003 can start in parallel against a stable import surface instead of each inventing their own heading representation. Because every later module imports from here, this task is the single serialization point in the epic and is marked `parallel: false`.

The package is standard library only — no `import` of any third-party module, per the PRD's dependency constraint.

## Acceptance Criteria

- [ ] `md_toc/__init__.py` exists and makes `md_toc` importable as a package via `python3 -c "import md_toc"`.
- [ ] `md_toc/types.py` defines a `Heading` dataclass with exactly two fields: `level: int` and `title: str`.
- [ ] `Heading` supports value equality, so tests can assert `extract_headings(...) == [Heading(1, "Intro")]` directly.
- [ ] `md_toc/types.py` defines `EXIT_OK = 0`, `EXIT_STALE = 1`, and `EXIT_ERROR = 2`, matching the PRD's exit-code table (0 success, 1 stale TOC in check mode, 2 usage or I/O error).
- [ ] `Heading` is re-exported from `md_toc/__init__.py` so downstream modules may import it from either location.
- [ ] No module in the package imports anything outside the Python 3.11 standard library.
- [ ] `python3 -m unittest discover` runs cleanly against the new package (zero collected failures, even with no tests yet).

## Technical Details

Paths owned by this task, and no others:

- `md_toc/__init__.py`
- `md_toc/types.py`

`md_toc/types.py` implements:

```python
@dataclass(frozen=True)
class Heading:
    level: int
    title: str

EXIT_OK = 0
EXIT_STALE = 1
EXIT_ERROR = 2
```

Use `dataclasses.dataclass` from the standard library; `frozen=True` gives hashability and value equality for free, which keeps test assertions terse and prevents accidental mutation of parser output during rendering. `level` is the ATX heading depth, 1 through 6. `title` is the heading's raw text with the leading `#` run and surrounding whitespace already stripped — normalization is the parser's responsibility, not this type's.

The exit-code constants live in `types.py` rather than `cli.py` so that `--check` tests can assert against a named constant without importing the argparse layer.
