# Task: 置換プレビュー

## Description

パターン・フラグ・入力・置換文字列から、置換後の全文を生成する純粋モジュール `src/logic/replace.js` を実装する。US-4 に対応する。

置換パターン（`$1`、`$<name>`、`$&`、`$$` 等）の解釈は JavaScript の `String.prototype.replace` と完全に一致させる。独自解釈を持ち込むと、ユーザがこのツールで確認した結果を実コードに移したときに食い違う。

## Acceptance Criteria

- [ ] `src/logic/replace.js` が `runReplace(pattern, flags, input, replacement)` を export する
- [ ] 成功時に `{status:"ok", output:string}`、パターン不正時に `{status:"error", message:string}` を返す
- [ ] `$1` `$2` … による番号付きグループの参照が機能する
- [ ] `$<name>` による名前付きグループの参照が機能する
- [ ] `$&`（マッチ全体）、`` $` ``（前方）、`$'`（後方）、`$$`（リテラルの `$`）が仕様どおり解釈される
- [ ] 存在しないグループへの参照（`$9` など）が `String.prototype.replace` と同じ結果になる
- [ ] `g` フラグなしでは最初のマッチのみ、ありでは全マッチが置換される
- [ ] 置換文字列が空文字列のとき、マッチ部分が削除された結果を返す（「未入力」の判定は UI 層の責務であり、このモジュールは空文字列を正当な置換文字列として扱う）
- [ ] 不正パターンで例外を投げず、エラーオブジェクトを返す
- [ ] `test/replace.test.js` が上記を網羅し `node --test` で通る

## Technical Details

**シグネチャ**:

```js
/**
 * @param {string} pattern
 * @param {string} flags
 * @param {string} input
 * @param {string} replacement
 * @returns {{status:"ok", output:string}|{status:"error", message:string}}
 */
export function runReplace(pattern, flags, input, replacement) {}
```

**実装方針**: 置換パターンの解釈を自前で書かない。`new RegExp(pattern, flags)` を作り `input.replace(re, replacement)` にそのまま委譲する。これが「`String.prototype.replace` と一致させる」唯一確実な方法である。自前でパースすると必ず差異が出る。

このモジュールの責務は、パターンのコンパイル失敗を例外ではなく戻り値として扱うことと、境界の挙動をテストで固定することにある。

**空の置換文字列の扱い**: 「置換文字列が空のときプレビューを出さない」という US-4 の受け入れ基準は UI の表示判断であり、このモジュールには持ち込まない。ここでは空文字列も正当な入力として削除置換を返す。

**禁止事項**: `document` / `window` / `localStorage` / `self` への参照を書かない。
