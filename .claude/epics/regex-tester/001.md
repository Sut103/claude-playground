## Technical Details

**確定させるデータ契約**（`src/logic/types.js`、JSDoc typedef のみで実行コードを持たない）:

```js
/**
 * @typedef {Object} CaptureGroup
 * @property {number} number            1 始まりのグループ番号
 * @property {string|null} name         名前付きグループ名。無名なら null
 * @property {string|undefined} value   捕捉文字列。不参加なら undefined
 */

/**
 * @typedef {Object} MatchResult
 * @property {string} value             マッチ全体の文字列
 * @property {number} start             入力中の開始インデックス
 * @property {number} end               終了インデックス（排他）
 * @property {CaptureGroup[]} groups    グループ一覧（番号順）
 */

/**
 * @typedef {{status:"ok", matches:MatchResult[]}
 *          |{status:"error", message:string}} MatchOutcome
 */

/**
 * @typedef {Object} Segment
 * @property {"text"|"match"|"zero-width"} kind
 * @property {string} value             zero-width のときは ""
 * @property {number} [matchIndex]      match / zero-width のとき matches[] への添字
 */

/**
 * @typedef {Object} HistoryEntry
 * @property {string} pattern
 * @property {string} flags
 * @property {number} savedAt           epoch ミリ秒
 */
```

**ディレクトリ構造**:

```
index.html
styles.css
README.md
src/logic/{types,matcher,highlight,replace,history}.js
src/worker/{regex-worker,worker-client}.js
src/ui/{app,render}.js
test/
```

このタスクでは `types.js` 以外の `src/logic/*` と `src/worker/*` は作らない（後続タスクの担当ファイルであり、空ファイルを置くと衝突の元になる）。`src/ui/app.js` のみ、HTML から読める最小のプレースホルダを置く。

**`package.json` について**: 置かない。`node --test test/` は `package.json` なしで動作する。テストファイルは `.js` 拡張子で ES モジュール構文を使うため、Node が ESM として解釈できるよう **テストファイルは `.mjs`** とするか、`package.json` に `{"type":"module"}` のみを置くかを決める。依存を増やさない前提でどちらかに統一し、README に明記する。
